# Bheem Nagar Times — News Publisher

A Spring Boot + Thymeleaf newspaper publishing studio for turning raw Hindi news into a consistent Bheem Nagar Times newspaper layout.

## Stack
- Java 21
- Spring Boot 3.5.5
- Thymeleaf
- HTML/CSS
- OpenAI-compatible API integration (optional)
- Flying Saucer PDF

## Run
```bash
mvn spring-boot:run
```

Open http://localhost:8080

See the project documentation for configuration and Docker usage.
